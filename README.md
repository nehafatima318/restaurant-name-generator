# restaurant-name-generator
Restaurant Name Generator | Python, LangChain, Google Gemini API, Streamlit

Developed an interactive AI-powered web application using Streamlit and LangChain to generate creative restaurant names based on selected cuisines.

Integrated Google Gemini API to generate restaurant names and corresponding menu suggestions through chained LLM prompts.

Implemented dynamic prompt templates and structured outputs to deliver cuisine-specific restaurant concepts and menu items.

Secured API credentials using environment variables and .env configuration, with Git/GitHub for version control.
